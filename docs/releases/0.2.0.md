# Lotse 0.2.0

A release of the brokers, the console and the SDKs. Its cluster version is 0.2: a 0.2 node runs beside 0.1 nodes during a rolling upgrade, and the new formats are written only once `lotse upgrade finalize` raised the cluster version to 0.2.

## What changed

- **Storage quotas.** (Written with the change that builds them.)
- **Segments close by age.** A runtime stream's or queue's active segment closes once it has held data for an hour, so a drained queue or a stream past its retention frees its space without new data. Set the node's age with `[cluster] segment_ms`, and a resource's with `segment.ms` through `AlterConfigs` once the cluster version is 0.2 ([ADR 0146](https://github.com/pierrejochem/lotse/blob/main/docs/adr/0146-segments-close-by-age.md)).

## Upgrading

Upgrade one node at a time with the restart turn, as for any release ([ADR 0127](https://github.com/pierrejochem/lotse/blob/main/docs/adr/0127-rolling-upgrades-with-a-cluster-version-and-restart-turns.md)), then raise the cluster version with `lotse upgrade finalize`.
