# 22. Brand: Lotse and the Fairway mark

- Status: Accepted
- Date: 2026-10-27

## Context

The project needed a name and an identity that say what it does without nautical kitsch.

## Decision

The broker is called Lotse (a harbour pilot). The mark, Fairway, takes signal flag H ("I have a pilot on board"): navy and red halves, three queue lanes converging into one stream, left to right. Colours, type (Schibsted Grotesk, IBM Plex Mono), spacing and voice are defined in [docs/brand](../brand/); `tokens.json` is the source of truth for every UI.

## Consequences
- UI copy follows the brand voice: calm, exact, short.
