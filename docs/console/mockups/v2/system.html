Colour system

Controls, focus and state colours in light and dark, with two options for the primary colour. Add ?theme=dark to the address for dark. Every other mockup uses variant B.

A. Signal red primary

As today: red is the primary action, the active tab and the error colour. The danger button is red too, told apart by icon and word.

Focus rings

One ring colour for every control: a blue that appears nowhere else in the system, so it never reads as an error. 2 px, 2 px offset, plus a 4 px halo in the surface colour so it stays visible next to a dark fill.
