Row menus

One menu per row type. Delete and revoke last, in the danger colour with an icon and a word.

User ci-bot
Token nightly export
Certificate of mats.berg
Request for ci-bot
Session of ci-bot from 10.0.4.17

Confirm delete

Names the target, says what breaks, asks for the name typed.

Delete user ci-bot?

This removes the user and their role bindings. It ends 2 open sessions and revokes 1 token. Scripts that sign in as ci-bot will fail with an authentication error. To restore access, create the user again and issue new credentials.

The button enables when the text matches.

Opens with focus on Cancel (a destructive confirm). Tab stays inside the dialog. Esc cancels. Focus returns to the control that opened it. The danger button enables when the name matches.

Delete your user

Same pattern, and it says you are signed out. If you are the only cluster admin the dialog refuses instead.

Delete your user?

You are signed in as ines.lund. Deleting this user signs you out at once. You cannot sign in again until another cluster admin creates the user.

The button enables when the text matches.

You are the only cluster admin. Make another user a cluster admin first.

Opens with focus on Cancel (a destructive confirm). Tab stays inside the dialog. Esc cancels. Focus returns to the control that opened it.

Revoke all sessions of a user

Names the scope. Users can sign in again, so no typed name.

Revoke all sessions of ci-bot?

Ends all 2 open sessions of ci-bot, on 10.0.4.17 and 10.0.4.18. Tokens made before now stop working; make a new token to sign in with a token again. Password and certificate sign-in still work.

Opens with focus on Cancel (a destructive confirm). Tab stays inside the dialog. Esc cancels. Focus returns to the control that opened it.

Revoke your sessions

Says that the current session ends.

Revoke your sessions?

This ends the session you are using. You will have to sign in again.

Opens with focus on Cancel (a destructive confirm). Tab stays inside the dialog. Esc cancels. Focus returns to the control that opened it.

Revoke token

Names the token and its owner.

Revoke token nightly export of ci-bot?

Scripts that use this token fail with an authentication error at once. This cannot be undone. Create a new token to restore them.

The button enables when the text matches.

Opens with focus on Cancel (a destructive confirm). Tab stays inside the dialog. Esc cancels. Focus returns to the control that opened it.

Revoke certificate

The serial is in the title; the typed text is the principal.

Revoke certificate 4f:a1:0a of mats.berg?

Every node ends the connections that use certificate 4f:a1:0a, now. mats.berg must request a new certificate to sign in this way again. This cannot be undone.

The button enables when the text matches.

Opens with focus on Cancel (a destructive confirm). Tab stays inside the dialog. Esc cancels. Focus returns to the control that opened it. Revoking ends connections on every node, so the typed name matters.

Create token

Not a destructive confirm, so focus starts on the Name field.

Create token

A token lets a script or tool sign in as its owner. You see the token once, after you create it.

What the token is used for, for example nightly export.
    Who the token signs in as. Only cluster admins can choose someone else.

    Opens with focus on Name. Tab stays inside. Esc cancels. Focus returns to Create token.

    Token created

    Second step of the same dialog. Focus is on the read-only field.

    Token created

    Copy the token now. It cannot be shown again. Store it in a secret manager, not in a repository.

    Esc does nothing on this step, so the token is not lost by accident. The status line is empty until Copy, then says "Copied to the clipboard". Focus returns to Create token and the new token is in the list. Pressing Done without Copy opens the confirm below.

    Close without copying

    Shown when Done is pressed before Copy. Go back is the default.

    Close without copying the token?

    You have not copied the token. It cannot be shown again.

    Owner combobox, open

    Arrow keys move the highlight, Enter picks, Esc closes the list.
